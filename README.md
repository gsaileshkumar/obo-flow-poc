# obo-flow-poc

POC: Azure Entra ID → MCP → Google ADK agent, demonstrating an end-to-end
delegated-identity chain via OAuth On-Behalf-Of (OBO).

See [`poc/README.md`](./poc/README.md) for setup, run instructions, and how
to verify the chain, and [`poc/PREREQUISITES.md`](./poc/PREREQUISITES.md)
for the required Entra ID app registrations.
